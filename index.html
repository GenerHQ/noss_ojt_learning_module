Complete Network Terminology · Components & Daily Tools

Component / Term Function / Purpose Field Notes / Daily Usage
LAN / WAN Local Area Network (LAN) connects devices within a single location (office, building). Wide Area Network (WAN) connects multiple locations across distances (branch to main office). Daily operations involve LAN installation, WAN connectivity monitoring, and troubleshooting "No internet" issues across 234+ SSS locations.
IP Phone VoIP telephone that uses the network connection instead of traditional phone lines for voice communication. Common errors: "No TFTP response" → reconfigure IP via phone's ipconfig menu. "No Ethernet link" → check cable connection or port switching.
Access Point (AP) Device that extends wireless network coverage by converting wired signals into Wi-Fi for wireless clients. Daily AP install and decommission. Requires PoE (Power over Ethernet) from switch. Troubleshoot with ping to verify connectivity.
Switch Central device connecting multiple devices within a LAN. Forwards data using MAC addresses and manages network traffic. Port switching is common when relocating workstations. NMS handles VLAN configuration. Recabling may be needed if port is damaged.
IO (Information Outlet) Wall-mounted jack terminating horizontal cabling. End devices connect here via patch cable. Test with LAN Tester for continuity. Damaged IO requires replacement. Split cabling allows one IO to support both PC and IP Phone.
Patch Cable Short stranded UTP cable used to connect devices to IOs, or patch panels to switches inside the Data Cabinet. Prepared in various lengths (1.5m, 2.5m, 3m). Damaged patch cables cause "No Ethernet link" issues → replace via recabling.
Crimping / Recrimping Process of attaching RJ45 or RJ11 connectors to UTP cable using a Crimping Tool. Recrimping means re-terminating a faulty connector. Intermittent "No internet"? Recrimp using all 8 pins. A connector with only 4 pins crimped causes random disconnections. Always test with LAN Tester after crimping.
RJ45 / RJ11 RJ45 = 8-pin connector for Ethernet (LAN, IP Phone). RJ11 = 4-pin connector for analog telephone lines. RJ45 used for LAN, IP Phone, Access Points. RJ11 used for direct telephone lines. Loose RJ45 causes "No Ethernet link". Replace via recrimping.
Data Cabinet Enclosure housing network equipment: switches, patch panels, and cable management. Organized data cabinet reduces troubleshooting time. Contains patch panels connected to switches via patch cables. Port switching happens inside the data cabinet.
Ticket / Escalation Formal request recorded in ITSM system. Ticket escalation means forwarding to other support level (NMS, CMS) when issue cannot be resolved. Client reports issue → ticket created → diagnose → if VLAN issue, escalate to NMS. If carrier issue, escalate to CMS. For other non-network-related issues, escalete to other Department . Always document resolution before closing ticket.
"No internet" End-user cannot access internet or network resources. One of the most common daily tickets. You may try: Check proxy settings (proxyserver828:3128), run ipconfig /release & /renew, ping gateway, verify physical connection, or try port switching.
"No Ethernet link" Physical layer issue: No signal detected between device and switch. Link light is off. Fix: Check patch cable, try recabling, test with LAN Tester, verify IO connection, or try port switching on switch.
"No TFTP response" IP Phone cannot download configuration from TFTP server. Phone powers on but cannot register. Fix: Reconfigure IP address via phone's ipconfig menu. Set wired VLAN (32/33/34 based on floor). May require NMS assistance.
Ping Command-line tool testing connectivity between devices by sending ICMP (Internet Control Message Protoco) echo requests. ping 10.1 -t = continuous test to gateway.
ping 1.1.1.1 = external connectivity.
ping wfh.sss.gov.ph = VPN endpoint test.
Ipconfig Command-line tool displaying IP configuration, MAC address, DHCP status, and DNS settings. ipconfig /all → get MAC address for NMS.
ipconfig /release & /renew → refresh IP lease. First step for "No internet" troubleshooting.
Proxy (proxyserver828:3128) Intermediary server filtering internet requests. Required for intranet access within SSS network. Main proxy: proxyserver828:3128. First-time AD users MUST configure proxy after LAN connection. Without proxy → "No internet" for intranet sites.
Port switching Moving a network cable from one switch port to another to resolve connectivity issues or accommodate workstation moves. Common fix for "No Ethernet link" or dead ports. When relocating a workstation, the corresponding switch port must also be switched. Document port changes.
Recabling Replacing an entire network cable (patch cable or horizontal run) due to damage or failure. Rodent damage is #1 cause for recabling. Also used when LAN Tester shows open/short circuit. Recabling solves many "No Ethernet link" tickets.
LAN Tester Device testing continuity, pin mapping, shorts, opens, and split pairs in UTP cables. Essential daily tool. Test every cable after crimping/recrimping. Verify IO terminations. Never leave for a ticket without it.
Crimping Tool Tool attaching RJ45/RJ11 connectors to UTP cable by pressing metal pins through wire insulation. Used daily for preparing patch cables and recrimping faulty connectors. Requires proper pressure — too light = intermittent connection.
UTP Cable Unshielded Twisted Pair cable (Cat5e, Cat6) for network connections. Four twisted pairs inside outer jacket. Standard for LAN drops, patch cables, and IO terminations. Cat6 preferred for new installations. Keep spare bulk UTP spool for onsite recabling.
MyPCInfo Internal SSS application displaying hostname, IP address, MAC address, and system information instantly. Daily tool. Faster than CMD for getting client info. MAC address needed for NMS IP assignment. Use before escalating any ticket.
AnyDesk Remote desktop software used for assisting clients in Work-From-Home setups. Client must be on separate WiFi/mobile data. Verify with ping before connecting. Never share credentials via email.
FortiClient VPN client for secure Work-From-Home access to SSS network. Requires Department Head approval. IPSEC VPN to wfh.sss.gov.ph. After login, ping prs:7777/m8 to verify.
NMS (VLAN config) Network Management Section responsible for VLAN configuration, IP addressing, and switch management. When client has IP but cannot access resources → escalate ticket to NMS for VLAN reconfiguration. Provide hostname, MAC address, and switch port.
Client End-user reporting the issue. The person requesting technical assistance. Probe the client first: Ask about recent changes (station transfer, new PC, office move) before touching hardware. Good client communication = faster resolution.

Crimping Standards · T568A vs T568B

Straight-through Cable

End 1
T568B
════════════►
End 2
T568B

Same standard on both ends (T568B to T568B or T568A to T568A).

Purpose: Connects different devices (PC to Switch, PC to Router, IP Phone to Switch).

Daily usage at SSS: 95% of cables made are straight-through — used for connecting PCs, IP Phones, and Access Points to switches.

Crossover Cable

End 1
T568B
══✗══►
End 2
T568A

Different standards on each end (T568B to T568A). Transmit pins connect to Receive pins.

Purpose: Connects similar devices directly (PC to PC, Switch to Switch, Router to Router) without a switch/hub.

Note: Modern switches support Auto-MDI/X, automatically detecting cable type — crossover cables are rarely needed today.

Pin T568A Color T568B Color Pair Function
1 White/Green White/Orange Tx+ (Transmit positive)
2 Green Orange Tx- (Transmit negative)
3 White/Orange White/Green Rx+ (Receive positive)
4 Blue Blue Unused / PoE
5 White/Blue White/Blue Unused / PoE
6 Orange Green Rx- (Receive negative)
7 White/Brown White/Brown Unused / PoE
8 Brown Brown Unused / PoE
Cable Type End 1 Standard End 2 Standard When to Use
Straight-through T568B (or A) T568B (or A) — SAME PC → Switch, IP Phone → Switch, AP → Switch, PC → Router
Crossover T568B T568A — DIFFERENT PC → PC, Switch → Switch, Router → Router (legacy devices)
Purpose & Usage: T568B is most common in the Philippines (compatible with US standards). T568A is required for US government contracts. Always keep both ends the SAME standard for straight-through cables. Mixing A/B creates a crossover cable.
Field Tip: Always double-check both ends before crimping. Intermittent "No internet"? Recrimp using all 8 pins — we once found a connector with only 4 pins crimped that caused random disconnections!
Memory Trick: Straight = Same (both ends identical) → connects Different devices.
Crossover = Crossed (ends different) → connects Same devices.

Essential Network Commands

ipconfig
Displays basic IP address configurations for all network adapters.
ipconfig /all
Shows detailed network settings, including MAC (Physical) addresses and DNS servers.
ipconfig /release
Releases the current DHCP IP address lease from the network adapter.
ipconfig /renew
Requests a new IP address configuration from the DHCP server.
ping 10.0.0.1 -t
Continuously pings the specified target until manually stopped (Ctrl + C).
ping 1.1.1.1
Tests basic internet connectivity using Cloudflare's public DNS server.
ping wfh.sss.gov.ph
Checks connectivity and resolves the IP address for the SSS Work From Home portal.
ping prs:7777/m8
Checks connectivity and resolves the IP address for the SSS M8 system.
ncpa.cpl
Opens the Network Connections window directly from Control Panel.
Pro Tip: Use ipconfig /all to find the MAC address required for NMS IP assignment. ping -t is useful for monitoring intermittent connection drops. ncpa.cpl instantly opens the Network Connections window.

Switch & VLAN Fundamentals

Green LED = Endpoint has PC only
Amber LED = Endpoint has both PC + IP Phone (PoE active)
Trunk lines:Normally (as per NMS), Ports 1 and 24 on Alcatel switches are often trunk lines — DO NOT connect end devices to these ports!
VLAN Mismatch: When PC gets IP address but cannot access network resources → escalate to NMS for VLAN reconfiguration immediately. Don't waste hours troubleshooting.
Port Assignment: When transferring a workstation, the corresponding port number at the switch in the data cabinet must also be transferred to ensure connectivity.
IP Phone VLANs

32 = Ground and Second Floor, 33 = 4th-7th Floors, and 34 = 8th Floor and Above

Note: Manual configuration of the IP phone VLAN applies to Cisco switch connections, not Alcatel.

Troubleshooting · Common Issues & Fixes

🔴 No TFTP response (IP Phone): Reconfigure IP via phone's ipconfig menu, set wired VLAN (32/33/34 based on floor).
🟡 Intermittent LAN connection: Check RJ45 crimp (all 8 pins must be properly terminated), inspect for loose connector, or check for rodent-damaged cable.
🟢 IP pingable but no internet/browser: Disable DNS (ncpa.cpl → IPv4 properties) or verify proxy settings are correct.
🔵 2 IP addresses detected: FortiClient closed improperly. Deactivate it via user admin or sync the client account, then restart. Also, ensure the device is not connected to both LAN and Wi-Fi simultaneously.
🟠 Printer not connecting: Check if printer is powered on, verify IP address (may need reconfiguration after move), check VLAN mismatch.
⚪ No ethernet link: Check physical cable connection, try different port on switch, verify IO is functional with LAN tester.

Tips & Best Practices · From the Field

Probe first: Always ask client about recent changes (station transfer, new PC, office move) before touching any hardware. It cuts diagnosis time in half.
Restart before panic: Simple PC restart resolves 20% of "no internet" issues, especially after IP changes or VPN use.

Loose RJ45 = gremlin: Intermittent connection? Recrimp using all 8 pins. A connector with only 4 pins crimped was causing random disconnections daily.
Rodent damage is real: Cable bites cause outages; always check under desks and ceiling trays. Re-cabling solved many cases.
VLAN mismatch escalation: When connection works but can't access resources, ask NMS to reassign VLAN immediately. Don't waste hours.
Document everything: Every resolution builds the knowledge base. Future interns and team members will thank you.

5S Workplace Organization Methodology

Direct Line & Telephony

Path: The network path originates from the PLDT Exchange and runs to the main XCT panel. From there, it connects to the Data Center XCT, routes to the local IDF, and terminates at the dedicated floor patch panel.

Troubleshooting: Static line often caused by loose handset or damaged cable. Replace cable or handset to resolve.

Direct Line Transfer: Process involves wiretapping to confirm line, then transferring to new port at data center.

Carrier Management Section (CMS): Handles all ISP coordination, PLDT relationships, and direct line provisioning.

Active Directory · First-Time Users

First-time AD login: Device must be connected via LAN (not Wi-Fi) for initial authentication.

After login: Must set up proxy server setting immediately (proxyserver828:3128) to establish network connectivity.

Active Directory error: If user encounters a "Wrong Credentials" prompt, the account may not be activated. Escalate and forward the concern to the Network Management Section (NMS) for activation.

Troubleshooting: If old laptop's IP is transferred to new laptop, old laptop may need temporary IP from NMS to allow AD login.

Structured Cabling Testing



Testing Process: One person at data cabinet, one at IO testing connections one by one using LAN tester.

Common Issues Found: Incorrect pinning, reverse port tagging, ports with no reading, damaged ports/connectors.

Documentation: Record all test results (pass/fail) with port numbers for future reference.

Remote Support & AnyDesk

WFH Remote Assistance: Client must be on separate/independent WiFi or mobile data (not corporate network).

Standard Steps: ipconfig /all → ping 1.1.1.1 → ping wfh.sss.gov.ph → ping 1.1.1.1 -t for continuous monitoring.

FortiClient Remote Gateway Options: wfh.sss.gov.ph (regular), svc.sss.gov.ph (service office), ./useradmin for Remote Gateway.

Security Note: Never share AnyDesk credentials via email. Use phone verification before connecting.
