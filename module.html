Crimping Standards · T568A vs T568B

PinT568A ColorT568B ColorPair Function
1White/GreenWhite/OrangeTx+ (Transmit)
2GreenOrangeTx- (Transmit)
3White/OrangeWhite/GreenRx+ (Receive)
4BlueBlueUnused / PoE
5White/BlueWhite/BlueUnused / PoE
6OrangeGreenRx- (Receive)
7White/BrownWhite/BrownUnused / PoE
8BrownBrownUnused / PoE
Purpose & Usage: T568B is most common in PH (compatible with US standards). T568A is required for US government contracts. Keep both ends the SAME standard for straight-through cable. Mixing A/B creates crossover cable.
Field Tip: Always double-check both ends before crimping. Intermittent connection? Recrimp using all 8 pins — we once found a connector with only 4 pins crimped!

Switch & VLAN Fundamentals

Port Indicators (Alcatel): Green = PC only endpoint | Amber = PC + IP Phone (PoE active)
Trunk lines: Ports 1 and 24 are often trunk lines — DO NOT connect end devices there.
VLAN Mismatch: When PC gets IP but can't access resources → escalate to NMS for VLAN reconfiguration immediately.

Troubleshooting · Common Issues

No TFTP response (IP Phone): Reconfigure IP via phone's ipconfig, set wired VLAN (32/33/34)
Intermittent LAN: Check RJ45 crimp (all 8 pins), loose connector, or rodent-damaged cable
IP pingable but no connection: Disable DNS (ncpa.cpl → IPv4) or check proxy settings
2 IP addresses: FortiClient improperly closed → deactivate via useradmin or client account sync
Printer not connecting: Check if printer is powered on, IP address reconfigure, or VLAN mismatch

Tips & Best Practices

Probe first: Ask about recent changes (station transfer, new PC) before touching hardware
Restart matters: Simple reboot fixes 20% of "no internet" issues
Loose RJ45: Recrimp using all 8 pins — intermittent connection solved
Rodent damage: Always check under desks / ceiling trays for cable bites
VLAN mismatch: Escalate to NMS immediately — don't waste hours guessing
Document everything: Every resolution builds the knowledge base
